# Facilitator 可直接复制的真人对话

三位测试者按 Green / Blue / Pink 分工，顺序逐条发送。**只复制灰框中的正文**，不用改词。按当前页面选择 Task A 或 Task B。

每组用于一个新的 Adaptive 讨论场景；不要把全部组连续粘进同一轮。逐条发送，六句后暂停观察；若上一轮自动尝试距今不足 30 秒，先等够再发。这里的角色标题只是观察目标，不保证模型每次选择该角色。不要 @Facilitator 来触发这些自动选角用例。所有具体事实均取自当前任务公共说明。
